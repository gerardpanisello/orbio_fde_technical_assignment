# Sample conversations

Scripted candidates talking to the real screening pipeline (extraction -> deterministic engine -> phrasing), then the recruiter summary. Generated by [`backend/scripts/sample_conversations.py`](../../backend/scripts/sample_conversations.py) with client `anthropic`, "today" fixed at 2026-10-13.

Regenerate (from `backend/`): `uv run --env-file ../.env python scripts/sample_conversations.py` (real model) or add `--mode fake` (offline).
